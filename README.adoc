
= Teragrep DPL Command-Line Executor (pth_16)

Teragrep DPL Command-Line Executor is an utility to run DPL queries from command-line.

== Features

-  Allows running Teragrep queries from command-line.

== Documentation

See the official documentation on https://docs.teragrep.com[docs.teragrep.com].

== Limitations

Uses spark-submit.

== Requirements

Requires Spark installation to be available, including `spark-submit` binary.

Requires the following Hadoop configurations from a valid cluster to be available in `HADOOP_CONF_DIR`:

- `core-site.xml`

- `hdfs-site.xml`

- `yarn-site.xml`

Requires `interpreter.json` from `zep_01` to be available.

Requires `pth_10-shaded.jar` to be available.

== How to use

=== Usage

Replace any `/path/to/` to a valid path to the wanted resource.

Connecting to Kerberos secured clusters requires you to set `export KRB5CCNAME="/tmp/krb5cc_${UID}";` and then running `kinit` with valid credentials.

Example without arguments

[source,shell]
----
HADOOP_CONF_DIR=/path/to/hadoop JAVA_HOME=/usr/lib/jvm/java-11 /path/to/spark/bin/spark-submit \
  --verbose \
  --deploy-mode client \
  --master yarn \
  --executor-memory 5G \
  --total-executor-cores 8 \
  --jars /path/to/pth_10-shaded.jar \
  --files /path/to/interpreter.json \
  /path/to/pth_16-jar-with-dependencies.jar
----

Results into

[source,json]
----
{"_time":"2026-01-27T13:37:00.000+02:00","_raw":"Welcome to Teragrep®"}
----

Custom query

[source,shell]
----
HADOOP_CONF_DIR=/path/to/hadoop JAVA_HOME=/usr/lib/jvm/java-11 /path/to/spark/bin/spark-submit \
  --verbose \
  --deploy-mode client \
  --master yarn \
  --executor-memory 5G \
  --total-executor-cores 8 \
  --jars /path/to/pth_10-shaded.jar \
  --files /path/to/interpreter.json \
  /path/to/pth_16-jar-with-dependencies.jar \
  '| makeresults count=1 | eval _raw="this is a custom query"'
----

Results into

[source,json]
----
{"_time":"2026-01-27T13:37:54.000+02:00","_raw":"this is a custom query"}
----

Results can be piped into a file

[source,shell]
----
HADOOP_CONF_DIR=/path/to/hadoop JAVA_HOME=/usr/lib/jvm/java-11 /path/to/spark/bin/spark-submit \
  --verbose \
  --deploy-mode client \
  --master yarn \
  --executor-memory 5G \
  --total-executor-cores 8 \
  --jars /path/to/pth_10-shaded.jar \
  --files /path/to/interpreter.json \
  /path/to/pth_16-jar-with-dependencies.jar \
  '| makeresults count=1 | eval _raw="this is a custom query"' | tee output.json
----

Results into

[source,json]
----
{
  "_time": "2026-01-27T13:54:24.000+02:00",
  "_raw": "this is a custom query"
}
----
